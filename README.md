# Planet Job Portal

**Planet Job Private Limited** | *Talent with Opportunity*
Laravel 12 · PHP 8.3 · MySQL · Tailwind CSS

A full job portal with separate Admin, Employer, and Job Seeker panels.
See `SCHEMA.md` for the database design and a running log of what's been
built in each pass.

## Setup

> **Note on `vendor/`:** this download includes every file of the project
> *except* `vendor/` (Composer's downloaded package cache — Laravel
> framework itself, Sanctum, etc). That folder is regenerated by
> `composer install` and is never meant to be distributed by hand; running
> it below rebuilds it from `composer.json` in under a minute.

```bash
composer install
npm install

cp .env.example .env
php artisan key:generate

# Configure DB credentials in .env, then:
php artisan migrate --seed
php artisan storage:link

npm run build     # or `npm run dev` while developing, for hot reload

php artisan serve
```

### Background jobs

Two scheduled commands need the Laravel scheduler running:

```bash
# One cron entry on the server, standard Laravel requirement:
* * * * * cd /path-to-project && php artisan schedule:run >> /dev/null 2>&1

# Or run manually while developing:
php artisan schedule:work
```

- `jobs:expire` — daily; closes jobs whose deadline has passed
- `jobs:send-alerts {instant|daily|weekly}` — emails job-alert digests

Notifications (new application, status change, job alert) use the `mail`
and `database` channels — run a queue worker so they don't block requests:

```bash
php artisan queue:work
```

## Security notes

- Role-based access via `role` middleware + Policies (admin bypasses all
  checks via `Gate::before`).
- Login is rate-limited two ways: route-level `throttle:5,1` and a
  per-account+IP `RateLimiter` lockout (60s cooldown) in
  `AuthenticatedSessionController`.
- All forms use Laravel's CSRF protection (built into `@csrf`) and
  dedicated `FormRequest` classes for validation — nothing is mass-assigned
  without an explicit `fillable` array.
- File uploads are restricted by MIME/type and size in each `FormRequest`
  (resumes: pdf/doc/docx, 5MB; images: 2–4MB) and stored under UUID
  filenames via `FileUploadService`, never the original filename.
- `bootstrap/app.php` and route groups keep the three panels fully
  separated — an employer route is unreachable by a jobseeker account
  even with a guessed URL, because `EnsureUserHasRole` aborts with 403.

## Performance notes

- List queries eager-load relationships (`with(['company', 'category', ...])`)
  to avoid N+1s — see `JobSearchService`, `HomeController`, all panel
  dashboards.
- Indexes are on every foreign key (via `constrained()`) plus `status`,
  `is_featured`, and `role` where they're filtered on (see migrations).
- Pagination (`paginate()`) is used on every list endpoint, web and API —
  nothing loads an unbounded collection.
